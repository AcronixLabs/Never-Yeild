# Never Yield

A dark charcoal + gold theme for [Omarchy](https://omarchy.org).

Washed-out charcoal backgrounds (`#0f0f14`) with a copper-gold accent
(`#c59043`) and brushed metal grays — a cold, industrial dark theme with
gold leaf highlights.

## Palette

| Role | Color |
|------|-------|
| Background | `#0f0f14` |
| Foreground | `#d8d8d8` |
| Accent | `#c59043` |
| Selection | `#2a2a33` |
| Gold | `#d4af37` |

## Install

```
omarchy theme install https://github.com/AcronixLabs/Never-Yeild.git
```

Installs as **never-yeild** in the theme picker (`Super + theme` or
Omarchy menu → Install → Style → Theme).
